# TOEFL BLAST

## Deskripsi
TOEFL BLAST adalah platform latihan TOEFL gratis terbaik yang dirancang untuk membantu siswa meraih skor impian mereka. Platform ini menyediakan simulasi real-test, ribuan soal latihan, dan sistem pelacakan kemajuan yang komprehensif.

## Fitur Utama
- **Simulasi Ujian Lengkap**: Pengalaman ujian TOEFL yang realistis dengan timer.
- **Latihan Per Bagian**: Fokus pada Listening, Structure, atau Reading secara terpisah.
- **Analitik Kemajuan**: Pantau perkembangan skor Anda dari waktu ke waktu.
- **Gratis Selamanya**: Akses ke semua fitur tanpa biaya berlangganan.

## Teknologi yang Digunakan
- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS, shadcn/ui
- **Animasi**: Framer Motion
- **Database/Backend**: Firebase

## Cara Menjalankan Secara Lokal

1. Clone repositori:
   ```sh
   git clone <URL_REPPOSITORI>
   ```

2. Masuk ke direktori proyek:
   ```sh
   cd toefl-triumph
   ```

3. Instal dependensi:
   ```sh
   npm install
   ```

4. Jalankan server pengembangan:
   ```sh
   npm run dev
   ```
